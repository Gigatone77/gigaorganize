# Changelog

All notable changes to GigaOrganize are documented in this file.

## [1.0.0] - 2026-09-03

### Added
- First public release of GigaOrganize (GTK4/libadwaita).
- Pages: Disk Usage, Duplicates, Cleanup, File Organizer, System Info.
- Recoverable cleanup: caches are MOVED to a hidden `.gigaorganize-trash` bin
  instead of being hard-deleted.
- Console entry point fixed: `gigaorganize` now launches correctly
  (`gigaorganize.main:main`).
